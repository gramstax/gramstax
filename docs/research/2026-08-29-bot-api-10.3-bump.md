### 3.2 Rich validation engine (`engine.ts`)

Current rich surface (53-54 tags) exhaustively validated via 3 centralized specs + rich-limit guard:

- `TemplateEngine._TELEGRAM_REQUIRED_ATTRS` — `engine.ts:325`
- `TemplateEngine._TELEGRAM_ATTR_VALUE_VALIDATORS` — `engine.ts:358`
- `TemplateEngine._TELEGRAM_ALLOWED_ATTRS` — `engine.ts:468`
- `TemplateEngine.validateBlockGMessageRich` — `engine.ts:3539` (32768 chars / 500 blocks / 16 nesting / 20 columns)
- `TemplateEngine.validateTemplate` — `engine.ts:3682` (23 steps, steps 5-7 are Telegram rich, steps 22-23 are PAGE)

**10.3 new rich validators needed:**

- `<table is_compact>` — 10.3 adds `is_compact` boolean; currently `engine.ts:501-502` only allows `bordered`/`striped` on `table`. Add `is_compact` there and in `_TELEGRAM_ALLOWED_ATTRS` + `_TELEGRAM_ATTR_VALUE_VALIDATORS` (boolean `() => null`).
- Expandable block quotation — new tags `RichBlockExpandableBlockQuotation` / `InputRichBlockExpandableBlockQuotation`. Not in `ALLOWED_BLOCKS_TELEGRAM_RICH` (`engine.ts:174-227`). Decide: either add new Telegram rich tag(s) (if HTML tag representation exists, e.g. `<blockquote expandable>` already exists) or handle as rich-block level only (no template tag). Verify spec — if it is a new `blockquote` variant, `validateBlockGMessageRich` and allowed-blocks may need extension.
- Document block — `<document>` / `tg://document?id=` support. Currently no `document` rich tag in `ALLOWED_BLOCKS`. May need new `document` / `tg-document` handling and `src` validator allowing `tg://document?id=` (parallel to existing `tg://photo|video|emoji|audio` patterns at `engine.ts:384-392`).
- Button blocks — `RichMessageButton` / `RichBlockButtons` / `InputRichBlockButtons` / `RichTextButton`. These are rich-block level constructs, not HTML tags — they affect `InputRichMessage.blocks` typing and `validateBlockGMessageRich` block-count logic. If Gramstax exposes button helpers, new helper/builder may be needed (compare `blocks/keyboard.ts`).
- Zoom range — 10.3 `rich.d.ts` says `RichBlockMap.zoom: 13|14|...|20` (observed in live `node_modules/.bun/@grammyjs+types@3.28.0/node_modules/@grammyjs/types/rich.d.ts` tail) vs engine's `13-19` at `engine.ts:374` and validator `13-19` at `engine.ts:373`. Bump to `13-20` and update comment.
