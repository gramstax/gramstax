# Worker Thread Export

`WorkerThreadExport` is the core utility for managing worker threads in Gramstax. It provides zero-boilerplate RPC proxying, sequential launching, and typed inter-worker gateway communication.

## WorkerThreadExport.init

Initializes a worker thread export. This should be called at the bottom of your worker file.

| Parameter | Type                              | Required | Default | Description                                 |
| --------- | --------------------------------- | -------- | ------- | ------------------------------------------- |
| options   | [Export Options](#export-options) | yes      | -       | Configuration options for the worker export |

### Export Options

| Parameter | Type     | Required | Default              | Description                                             |
| --------- | -------- | -------- | -------------------- | ------------------------------------------------------- |
| path      | string   | yes      | -                    | Absolute path to the worker file (usually `__filename`) |
| WTInit    | class    | yes      | -                    | The worker class extending `WorkerThreadInit`           |
| WTLaunch  | class    | no       | `WorkerThreadLaunch` | A custom launcher class extending `WorkerThreadLaunch`  |
| wrap      | function | no       | -                    | Optional wrapper function for manual method definitions |

```typescript
import { WorkerThreadInit, WorkerThreadExport } from "gramstax";
import { fileURLToPath } from "url";

class MyWorker extends WorkerThreadInit {
  public mtdHello(name: string) {
    return `Hello ${name}!`;
  }
}

export const MyWorkerExp = WorkerThreadExport.init({
  path: fileURLToPath(import.meta.url),
  WTInit: MyWorker,
});
```

## WorkerThreadExport.gateway

Creates a typed gateway client proxy for inter-worker communication.

| Parameter | Type   | Required | Default | Description                                       |
| --------- | ------ | -------- | ------- | ------------------------------------------------- |
| path      | string | yes      | -       | The unique path name of the target gateway server |

```typescript
// Define the gateway proxy (usually in the server's file)
export const ServerGateway = ServerExp.gateway("my-gateway");

// In a client worker:
import { ServerGateway } from "./server";

class ClientWorker extends WorkerThreadInit {
  async run() {
    // Usage 1: Static-like (requires 'this' as first argument)
    const res1 = await ServerGateway.mtdHello(this, "Gramstax");

    // Usage 2: Constructor-based
    const server = new ServerGateway(this);
    const res2 = await server.mtdHello("Gramstax");
  }
}
```

## Exported Instance Methods

When you call `WorkerThreadExport.init`, it returns an object that includes all methods from your `WTInit` class (proxied as async RPC) plus the following:

### launchWorker

Launches the worker thread and waits for it to be ready.

| Parameter | Type  | Required | Default | Description                                  |
| --------- | ----- | -------- | ------- | -------------------------------------------- |
| argv      | any[] | no       | []      | Custom arguments passed to the worker thread |

```typescript
// In the main thread
const instance = await MyWorkerExp.launchWorker(["arg1", "arg2"]);
```

### gateway

Helper to create a gateway client for this specific worker's exported type.

| Parameter | Type   | Required | Default | Description                           |
| --------- | ------ | -------- | ------- | ------------------------------------- |
| path      | string | yes      | -       | The path of the gateway to connect to |

```typescript
export const MyGateway = MyWorkerExp.gateway("my-service");
```

## Base Classes

### WorkerThreadInit

Base class for all worker implementaitons.

| Property | Type            | Description                            |
| -------- | --------------- | -------------------------------------- |
| argv     | string[]        | Process arguments in the worker thread |
| id       | number          | The unique thread ID                   |
| rpc      | WorkerThreadRpc | Internal RPC handler                   |

Methods:

- `createGatewayServer(path, methods)`: Starts a gateway server in this worker.
- `createGatewayClient(path)`: Connects to another gateway server.

### WorkerThreadLaunch

Base class for main thread instances that manage a worker.

| Property | Type   | Description                 |
| -------- | ------ | --------------------------- |
| thread   | Worker | The Node.js Worker instance |
| threadId | number | The unique thread ID        |

Methods:

- `ready()`: Returns a promise that resolves when the worker is fully initialized.
- `kill()`: Terminates the worker thread.
- `request(method, params)`: Manual RPC request.

## Features

### Zero-Boilerplate RPC

All methods defined in your `WTInit` class are automatically available on the exported instance.

- **Main Thread**: `await MyWorkerExp.mtdName()`
- **Worker Thread**: Methods are called locally.

### Sequential Launching

`launchWorker()` is asynchronous and waits for the worker's internal `mtdReady` signal. This ensures that the worker is fully set up and its RPC listeners are active before the promise resolves.

### Proxy Reliability

The underlying `Proxy` implementation explicitly ignores property lookups for `then`, preventing `Async/Await` from mistaking the proxy for a `Promise` itself. This resolves issues with recursive property access and unhandled rejections during initialization.
