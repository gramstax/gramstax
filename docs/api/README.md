# API Documentation

- **[01-cache-external.md](01-cache-external.md)**: Documentation for `CacheExternal`, the caching adapter extending `Keyv`.
- **[02-core-bot.md](02-core-bot.md)**: Documentation for the main `Gramstax` class and `Bot` configuration.
- **[03-core-ctx.md](03-core-ctx.md)**: Documentation for the `Ctx` class, properties, and methods.
- **[04-page-manager.md](04-page-manager.md)**: Documentation for `PageManager`, a utility for dynamic page loading.
- **[05-template-engine.md](05-template-engine.md)**: Documentation for `TemplateEngine`, handling custom template parsing and compilation.
- **[06-template-manager.md](06-template-manager.md)**: Documentation for `TemplateManager`, responsible for managing and hot-reloading templates.

- **[10-thread-main-pool.md](10-thread-main-pool.md)**: Documentation for `ThreadMainPool`, multi-thread manager.
- **[11-thread-export.md](11-thread-export.md)**: Documentation for `ThreadExport`, the unified thread initialization helper.
