## Ctx.PAID\_MEDIA\_STARS\_MAX property

Maximum Stars price for a `<g-paid-media>` paywall.

**Signature:**

```typescript
static readonly PAID_MEDIA_STARS_MAX = 25000;
```

## Remarks

The Bot API `sendPaidMedia` `star_count` accepts 1–25000 Stars per purchase (source: `https://core.telegram.org/bots/api#sendpaidmedia`).
