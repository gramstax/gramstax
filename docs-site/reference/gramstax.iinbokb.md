## IInBoKb type

Union type for both inline and reply keyboards.

**Signature:**

```typescript
type IInBoKb = IBottomKb | IInlineKb;
```
**References:** [IBottomKb](./gramstax.ibottomkb.md), [IInlineKb](./gramstax.iinlinekb.md)

## Remarks

Allows methods to accept either keyboard type.
