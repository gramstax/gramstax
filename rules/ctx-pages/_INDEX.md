# GRAMSTAX RULES INDEX

This directory contains modularized rules for Gramstax development. AI agents should refer to these Markdown files based on the relevant context.

## Target Folder

- Rule set name: `ctx-pages`
- Intended source folder: `<PROJECT>/src/pages`
- Usage rule: apply these rules when creating or editing page-related files in the matching pages directory for the target project or template.

## Rule Pages

- `./ROUTING_FLOW.md`: Logic flow, routing, and session handling.
- `./TEMPLATES_RENDERING.md`: Template syntax, rendering, and conditional logic.
- `./KEYBOARDS.md`: Keyboard blocks (kbk), labels (kbl), and reuse patterns.
- `./BASE_BLOCKS.md`: Base block usage and ID naming.
- `./PAGE_STRUCTURE.md`: Internal class composition, suffixes, and ordering.
- `./VARIABLE_NAMING.md`: Standardized shorthands (bi, kb, da).
- `./EXAMPLES.md`: Reference implementations and code snippets.
